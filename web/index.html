To a screen reader, every chart in a textbook says one word: image.

Raised reads the charts in a chapter, checks every number it reads against the pixels, and gives the student a data table, a description, a sound they can explore with the arrow keys, and a tactile graphic with braille labels ready for swell paper.

Every output is a draft for the transcriber, with anything uncertain flagged for review. Nothing you upload is stored.

            How Raised checks its own reading

            1. Reads the meaning. NVIDIA Nemotron 3.5 Super VL reads the chart three times: type, axes, tick labels, series and a first reading of every value.
            2. Measures the pixels. Plain code finds the tick labels, fits the axis scale, and measures every line, bar and point by colour.
            3. Settles disagreements. Where the two readings differ, both are redrawn over the original and the one that matches the pixels wins. Anything still uncertain is flagged for you.
            4. Explains, without inventing. NVIDIA Nemotron 3 Ultra writes the description and checks the caption against the data. Code rejects any number that is not in the table.
            5. Makes it touchable. The tactile graphic and braille are generated from the checked table with liblouis, following the BANA tactile graphics guidelines.

            All model calls run on Nebius Token Factory. NVIDIA Nemotron 3.5 Lightning checks every sentence is supported by the data. See the measured accuracy.
